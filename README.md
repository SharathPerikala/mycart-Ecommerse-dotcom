## Deploy to GitHub Pages

This project deploys to [https://sharathperikala.github.io/mycart-Ecommerse-dotcom/](https://sharathperikala.github.io/mycart-Ecommerse-dotcom/) using GitHub Actions.

To enable deployment in the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Then push to `main` or manually run the **Deploy to GitHub Pages** workflow from the **Actions** tab. Once the workflow completes successfully, open the Pages URL above.
